MODEL 1: MUTUAL TWO-BODY GRAVITATION (BINARY STAR SYSTEM)
--------------------------------------------------------------------------------
1. Astrophysical Concept & Formulas:
   - Newton's Third Law states forces are equal in magnitude and opposite in 
     direction: F_12 = -F_21.
   - Universal Gravitation: F = G * M1 * M2 / r^2.
   - Center of Mass (COM) coordinates:
       R_com = (M1 * r1 + M2 * r2) / (M1 + M2) = 0 (origin).
       r1 = r * M2 / (M1 + M2),   r2 = r * M1 / (M1 + M2).
   - Both bodies orbit the COM with the same period T:
       T^2 = (4 * pi^2 / (G * (M1 + M2))) * a^3.
2. Numerical Parameters for Screen Space:
   - G = 1000.0, dt = 0.016.
   - Mass M1 = 600.0 (Primary Star, radius = 2.2).
   - Mass M2 = 200.0 (Secondary Star, radius = 1.4).
   - Initial Positions: pos1 = (-2.5, 0, 0), pos2 = (7.5, 0, 0).
   - COM position: (600*(-2.5) + 200*7.5) / 800 = 0 (fixed at origin).
   - Separation r = 10.0.
   - Circular speed v_rel = sqrt(G * (M1 + M2) / r) = sqrt(1000 * 800 / 10) = 282.8.
   - Screen-scaled orbital velocities perpendicular to position:
       v1 = (0, 0, -2.5),  v2 = (0, 0, 7.5).
3. Visual Implementation Details:
   - Render Body 1 as a rotating wireframe sphere of radius 2.2.
   - Render Body 2 as a rotating wireframe sphere of radius 1.4.
   - Render a small wireframe "+" crosshair at the origin (0,0,0) indicating COM.
   - Draw an active vector line connecting the two stars (action-reaction axis).
   - Store and draw wireframe trail loops showing dual concentric elliptical paths.

MODEL 2: MULTI-PLANET SOLAR SYSTEM (KEPLER'S THIRD LAW / VELOCITY PROFILES)
--------------------------------------------------------------------------------
1. Astrophysical Concept & Formulas:
   - Centripetal balance: F_c = m * v^2 / r = G * M_sun * m / r^2.
   - Circular orbital velocity: v_orb = sqrt(G * M_sun / r).
   - Kepler's Harmonic Law: T^2 = (4 * pi^2 / (G * M_sun)) * r^3 -> T proportional to r^(3/2).
   - Direct consequence: inner planets move significantly faster and complete 
     orbits rapidly, while outer planets crawl along massive circumferences.
2. Numerical Parameters for Screen Space:
   - G * M_sun = 5000.0.
   - Sun at origin (radius = 2.5 wireframe sphere).
   - Planet 1 (Inner, "Mercury"):
       r1 = 4.0,  v1 = sqrt(5000 / 4.0) = 35.35 -> scaled speed 3.5.
   - Planet 2 (Middle, "Earth"):
       r2 = 9.0,  v2 = sqrt(5000 / 9.0) = 23.57 -> scaled speed 2.3.
   - Planet 3 (Outer, "Jupiter"):
       r3 = 16.0, v3 = sqrt(5000 / 16.0) = 17.67 -> scaled speed 1.7.
   - Relative periods:
       T1 : T2 : T3 = (4)^(1.5) : (9)^(1.5) : (16)^(1.5) = 8 : 27 : 64.
3. Visual Implementation Details:
   - Draw full concentric circular orbit guide paths at radii 4.0, 9.0, and 16.0.
   - Render each planet as a wireframe box or octahedron.
   - Display dynamic speed readout labels above each planet showing v_orb.

MODEL 3: KEPLER'S SECOND LAW (EQUAL AREAS SWEPT IN EQUAL TIMES)
--------------------------------------------------------------------------------
1. Astrophysical Concept & Formulas:
   - Central gravitational force exerts zero torque: tau = r x F = 0.
   - Conservation of angular momentum: L = m * r * v_perp = constant.
   - Areal velocity is constant: dA/dt = L / (2 * m) = constant.
   - Periapsis/apoapsis speed relation: v_p * r_p = v_a * r_a.
2. Numerical Parameters for Screen Space:
   - Semi-major axis a = 9.0, eccentricity e = 0.65 (strongly elongated ellipse).
   - Sun located at focus: F1 = (c, 0, 0) where c = a * e = 9.0 * 0.65 = 5.85.
   - Perihelion distance: r_p = a * (1 - e) = 9.0 * 0.35 = 3.15.
   - Aphelion distance:   r_a = a * (1 + e) = 9.0 * 1.65 = 14.85.
   - Speed ratio: v_p / v_a = r_a / r_p = 14.85 / 3.15 = 4.71 (perihelion is 
     nearly 5x faster than aphelion).
   - Polar orbit radius: r(theta) = a * (1 - e^2) / (1 + e * cos(theta)).
   - Angular velocity increment: dtheta/dt = h / r(theta)^2.
3. Visual Implementation Details:
   - Render the Sun at focus (5.85, 0, 0).
   - At fixed time intervals (e.g., every 1.5 seconds), generate a swept surface wedge:
     lines drawn from the Sun's focus to the satellite's position at start and end of interval.
   - Fill/shade or hatch the swept wedge with wireframe lines.
   - Visual takeaway: wedges near perihelion are short and broad; wedges near 
     aphelion are long and thin. Both subtend identical geometric surface area.

MODEL 4: ORBITAL ENERGY & ESCAPE TRAJECTORIES (BOUND VS. UNBOUND REGIMES)
--------------------------------------------------------------------------------
1. Astrophysical Concept & Formulas:
   - Total mechanical energy: E = K + U = 0.5 * m * v^2 - G * M * m / r.
   - Escape velocity at radius R: v_esc = sqrt(2 * G * M / R).
   - Relation to circular speed: v_esc = sqrt(2) * v_circ ≈ 1.414 * v_circ.
   - Energy classification:
       * E < 0 (v < v_esc) : Bound closed orbit (Ellipse/Circle).
       * E = 0 (v = v_esc) : Parabolic trajectory (Marginally unbound).
       * E > 0 (v > v_esc) : Hyperbolic trajectory (Unbound flyby).
2. Numerical Parameters for Screen Space:
   - Earth at center (0,0,0), radius R = 3.0.
   - All 3 test craft launch from the same periapsis point: P0 = (0, 0, 4.0).
   - Circular orbital speed: v_circ = sqrt(G * M / r) = 5.0.
   - Escape speed: v_esc = sqrt(2) * 5.0 = 7.07.
   - Craft A (Bound Ellipse, E < 0): v0 = (5.8, 0, 0)  [v < v_esc].
   - Craft B (Parabola, E = 0):      v0 = (7.07, 0, 0) [v = v_esc].
   - Craft C (Hyperbola, E > 0):     v0 = (9.2, 0, 0)  [v > v_esc].
3. Visual Implementation Details:
   - Simultaneous launch from (0, 0, 4.0).
   - Real-time numerical integration using Velocity Verlet or semi-implicit Euler.
   - Craft A forms an elliptical closed loop.
   - Craft B curves away and its trajectory becomes parallel to infinity.
   - Craft C flares outward along a wide hyperbolic asymptote.
   - Text overlay shows live Energy values: E_A < 0, E_B ≈ 0, E_C > 0.

MODEL 5: GEOSTATIONARY (GEO) VS. LOW EARTH ORBIT (LEO)
--------------------------------------------------------------------------------
1. Astrophysical Concept & Formulas:
   - Orbital period equation: T = 2 * pi * sqrt(r^3 / (G * M)).
   - Earth rotates about Y-axis with angular frequency omega_earth = 2 * pi / T_day.
   - For a geostationary orbit:
       T_orbit = T_day  ==>  r_geo = (G * M * T_day^2 / (4 * pi^2))^(1/3).
   - Real physical values from slides:
       * R_earth ≈ 6.37e6 m.
       * LEO: r ≈ 7.0e6 m, h ≈ 630 km, v ≈ 7.5 km/s, T ≈ 98 minutes.
       * GEO: r ≈ 4.22e7 m, h ≈ 35,800 km, v ≈ 3.1 km/s, T ≈ 24 hours (86164 s).
2. Numerical Parameters for Screen Space:
   - Earth radius = 3.0. Earth rotation period T_earth = 10.0 seconds.
   - LEO Satellite:
       r_leo = 4.2, speed fast, completing 1 orbit every 1.5 seconds.
   - GEO Satellite:
       r_geo = 10.5, speed matched perfectly to complete 1 orbit every 10.0 seconds.
3. Visual Implementation Details:
   - Earth rendered with rotating wireframe longitude lines.
   - A bright ground marker / line points from Earth center through the Prime Meridian.
   - LEO satellite races across continents, completing multiple loops rapidly.
   - GEO satellite hovers stationary above the exact same rotating longitude meridian,
     with a dashed radial line connecting the satellite directly to the surface target.

MODEL 6: HIGHLY ECCENTRIC COMETARY TRAJECTORY
--------------------------------------------------------------------------------
1. Astrophysical Concept & Formulas:
   - Highly eccentric Keplerian ellipse: 0.8 <= e < 1.0.
   - Perihelion: r_p = a * (1 - e) (close solar pass, extreme acceleration).
   - Aphelion:   r_a = a * (1 + e) (outer fringe, lingering velocity).
   - Speed extremes: v_p = sqrt((G*M/a) * ((1 + e) / (1 - e))),
                     v_a = sqrt((G*M/a) * ((1 - e) / (1 + e))).
   - Ratio: v_p / v_a = (1 + e) / (1 - e). For e = 0.85, v_p / v_a = 1.85 / 0.15 = 12.33x.
2. Numerical Parameters for Screen Space:
   - a = 12.0, e = 0.85.
   - Focus (Sun) at (c, 0, 0) with c = a * e = 10.2.
   - r_p = 12.0 * (1 - 0.85) = 1.8 (skims just outside solar radius = 1.2).
   - r_a = 12.0 * (1 + 0.85) = 22.2 (extends far out into deep space).
3. Visual Implementation Details:
   - Wireframe Sun at (10.2, 0, 0).
   - Draw complete elongated elliptical orbit track across the full screen width.
   - Comet body rendered with a trailing velocity-tail pointing directly away 
     from the Sun (anti-solar radiation pressure vector).
   - The comet crawls imperceptibly at aphelion, gathers speed along its inward 
     fall, whips violently around the Sun at perihelion in a split second, and 
     flings outward to begin another long cycle.
